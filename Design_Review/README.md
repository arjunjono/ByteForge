# ByteForge design review

This folder collects the current A1 + E1 files. Earlier design snapshots elsewhere in the repository are historical.

- [PCB](PCB/) — editable KiCad files with libraries, verified EasyEDA project backup, Gerbers and drills, schematic, routing, and LCD cable diagram.
- [Assembly](Assembly/) — full STEP and CadQuery source archive, plus the assembled and exploded preview. The full STEP is inside the ZIP to keep browser upload practical.
- [Verification](Verification/) — fabrication audit and saved schematic/PCB check reports.
- [Firmware and assembler](../fpga/) and [linked BOM](../BOM.csv) remain at their regular repository paths.

The parts have not been ordered. Physical fit and hardware testing remain pending.
