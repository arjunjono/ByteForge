**Rerun 2026-11-07 (revision 2)**: `sim/run_all.sh` (full, without `--fast`) was run in one pass: 17 entries, `failures: 0` (log: `results/run_all_full.out`). It now (a) counts every compile failure as a failure and exits nonzero - demonstrated with a temporary syntax error in `rtl/button_input.v` (7 compile failures reported, script exit status 7, file restored by hash, clean rerun exit 0; log `results/syntax_error_demo.log`); (b) runs the UNMODIFIED `assembler_tests.py` in a scratch directory that also holds `assembler.py` and the delivered `programs/*.asm/*.hex`, so **all 78 tests run, 0 skipped**, including the three demo-program tests and the delivered-.hex comparison (the script fails if fewer than 78 run or any skip appears). The `cpu/` copies of the original files were not modified. The mutation checks were rerun: all five detected.
Limits of these results: shortened timing in tb_demo (1 "ms" = 20 clocks, debounce 200 clocks, reset phases 2 000 clocks); production-length timing is covered only by tb_production_timing (no CPU in that test). The simulated clock in tb_production_timing is 37.038 ns (1 ps rounding) so time-based checks carry about 0.003 % error; clock-count checks are exact.

## Unchanged files
SHA-256 of the six CPU files, assembler.py, assembler_tests.py, cpu_tb.v and assembly_programs_tb.v were identical before and after all work (`/hashes_before` vs after compare: identical), and `fpga/cpu/` holds byte-identical copies. No CPU correction was needed.

## Mutation checks (`sim/run_mutations.py`, temporary copies; real RTL verified unchanged)
- M1 held request completes again: detected by tb_io_bus, tb_delay.
- M2 RAM address bit 13 dropped: detected by tb_io_bus.
- M3a SPI first bit = bit 0: detected by tb_io_bus, tb_spi_display. M3b DC inverted: detected by both.
- M4 debounce bypass: detected by tb_buttons.
- An earlier version of M1 (write pulse in RDY instead of at completion) was *not* detected - it is functionally equivalent while the request is held, so it was replaced by the mutation above.
- tb_demo/tb_board_top/tb_production_timing were not re-run per mutant.

## FPGA implementation - open-source flow only (`scripts/build_oss.sh`), rerun for revision 3 (pin remap: lcd_cs 75 -> 41, lcd_rst 86 -> 48)
Tools: Yosys 0.33, nextpnr-himbaechel 9691ce8, Apycula 0.35. Commands are in `scripts/build_oss.sh` (`synth_gowin -top tang_nano_20k_top`; `nextpnr-himbaechel --device GW2AR-LV18QN88C8/I7 --vopt family=GW2A-18C --vopt cst=../../constraints/byteforge.cst --freq 27 --seed 1`; `gowin_pack -d GW2A-18C`). The previous reports and bitstream were deleted and regenerated.
- **Pins**: `results/pin_verification.txt` (regenerated by `scripts/verify_pins.py`, which `build_oss.sh` calls, into `build/oss/pin_verification.txt`) maps each placed IO site back to a package pin through Apycula's GW2AR-18C QFN88 table and compares it with the requested pin: 16 of 16 ports match, 0 mismatches, including **lcd_cs -> IOB43A -> pin 41** and **lcd_rst -> IOR49B -> pin 48** (also lcd_din 73, lcd_clk 74, lcd_dc 77, lcd_bl 42, buttons/reset 25-31, clk 4, LEDs 15/16).
- **Resources (nextpnr report)**: LUT4 1,088 used of 20,736 (the nextpnr log line "LUT4: 1300/20736" also counts pass-through LUTs), DFF 396 / 15,552, ALU 304, MUX2_LUT5/6/7/8 292/123/52/17, **BSRAM 16 / 46** (RAM and ROM inferred as block RAM), BUFG 1, IOB 16 / 384, GSR 1, rPLL 0, DSP 0. Yosys: no latches (37 "No latch inferred" messages, 0 latch cells in the netlist).
- **Timing (nextpnr static timing, seed 1, one clock `clk`/27 MHz)**: **Fmax 85.90 MHz achieved vs 27 MHz constraint - PASS** (103.05 MHz at the pre-route estimate). Critical path: control-unit instruction register -> ALU -> flags register Z flip-flop. Fmax varies with seed/tool version (earlier runs: 82.60-84.43 MHz).
- **Warnings**: Yosys 36 warnings / 5 unique: the Gowin library's block-RAM mapping `PORT_A_WR_DATA` range-select-out-of-bounds messages (from the library's `brams_map.v`, not from this design) and one ABC "network is combinational". nextpnr: no warnings; informational "Cell O_sdram_* not found" lines (no SDRAM is used).
- **Bitstream**: `build/oss/byteforge.fs` regenerated by `gowin_pack`, sha256 3eec9fcf...14d5. **Never loaded on hardware.**
- **Unconstrained / not analysed**: nextpnr's SDC reader rejected parts of `byteforge.sdc`, so the run uses `--freq 27` only. The narrow input-port false paths (buttons, reset) were not applied and no input/output delay or external I/O timing was analysed. Gowin's own timing tool was not run.
